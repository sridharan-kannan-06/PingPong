# Ping Pong

## Overview
Simple 2 player Ping Pong Game made using pygame

## Power Ups
- **Smash** - next time ball hits the paddle it goes super fast(2.5x)
- **Auto Track** - paddle instantly teleports to ball's height

## Controls
### Player 1 (left paddle, blue)
- `W` - move up
- `S` - move down
- `D` - use smash power up
- `A` - use auto track power up
### Player 2 (right paddle, blue)
- `↑` - move up
- `↓` - move down
- `→` - use smash power up
- `←` - use auto track power up

## How to run
make sure  python and pygame installed then run the file.
```
pip install pygame
python pong.py
```
